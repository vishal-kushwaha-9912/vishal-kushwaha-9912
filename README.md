## 🚀 Featured Projects

### 🗳️ PulsePoll — Blockchain Voting App

**Real-time, tamper-proof polling on Monad blockchain. Built solo in 7 hours at Monad Blitz New Delhi V4.**

Think Google Forms — but every vote is permanently stored on-chain. Nobody can change the results. Ever. Each vote has a transaction hash anyone can verify independently.

**The Key Innovation — Gas Sponsorship**

Voters need **zero crypto knowledge**. No MetaMask. No gas fees. Just scan a QR code and tap. A relayer wallet pays the gas (~₹0.05) on their behalf. The organizer is charged ₹0.50 — 80% margin, and mainstream users never touch blockchain.

**Why Monad?**

10,000 TPS vs Ethereum's 15. When 200 people vote at the same second at a live event, Monad handles it instantly. That's not possible anywhere else.

**Why it's better than Google Forms?**

Google Forms results can be edited silently by the admin. PulsePoll results live on Monad blockchain permanently — tamper-proof, verifiable by anyone, forever. Perfect for colleges, corporates, hackathons, and any event where the result actually matters.

**What I Shipped (Solo, in One Day)**

- ✅ Solidity smart contract on Monad testnet
- ✅ Gas-sponsored voting — no wallet needed
- ✅ Live results updating every 4 seconds
- ✅ QR code share on every poll page
- ✅ Dark/light mode + Twitter share button
- ✅ Deployed on Vercel + open source on GitHub

**Technologies**

`Solidity` `Next.js` `Monad Blockchain` `Web3` `Vercel`
